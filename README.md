# Generic Collection

## Formål

Formålet med projektet er at demonstrere brugen af generiske klasser og generiske metoder i C#.

Projektet indeholder en generisk `Collection<T>`-klasse, som kan bruges til at gemme og håndtere forskellige typer objekter.

Programmet demonstrerer blandt andet:

- Tilføjelse af elementer.
- Fjernelse af elementer.
- Søgning efter elementer.
- Brug af generiske klasser med forskellige datatyper.
- Brug af en generisk `Max<T>`-metode.

## Opsætning

For at køre programmet skal følgende være installeret:

- .NET SDK
- En C#-kompatibel udviklingsplatform, eksempelvis Visual Studio.

Projektet kan åbnes i Visual Studio og køres med knappen Start.

Alternativt kan programmet køres fra terminalen med:

```bash
dotnet run
